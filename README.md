# Track Plan

本项目提供一个本地运行的航迹规划小工具：通过轻量级本地 Web 服务加载高德地图（AMap JS API），支持在浏览器中交互选取区域、自动计算航迹与摄影点，并将摄影点经纬度导出为 CSV 文件。

> 规划参数和 CSV 保存请求只在本机浏览器与 `127.0.0.1` 服务之间传输；地图脚本、底图和视口请求仍会访问高德地图服务。
>
> **坐标提示：**高德地图采用 GCJ-02。当前导出文件会明确标记为 GCJ-02，不能未经可靠转换就作为 WGS84 飞控任务文件使用。


## 核心功能

- 本地运行，自动打开默认浏览器，无需额外后端
- 交互式选点：点击地图即可添加多边形顶点，支持重置与重新选择
- 在局部米制坐标中自动生成最小面积旋转外接矩形，并提供优化航向、真实点距、航线间距与曝光间隔
- 支持航向/旁向矩形像幅、重复点和自交选区检查、任务规模保护
- 可切换底图（标准、卫星、实时路况），并根据需要显示/隐藏成像覆盖范围
- 一键导出带序号、航线号和 CRS 的摄影点坐标（UTF-8 BOM CSV），支持安全重名扩展


## 环境要求

- Python 3.10 或更高版本（仅使用标准库）
- 支持 ES2015+ 的现代浏览器（Chrome / Edge / Firefox 等）
- 高德地图 Web 端（JS API）Key


## 配置高德地图 Key

1. 前往高德开放平台 https://console.amap.com/dev/key/app 申请“Web 端（JS API）”类型的 Key。
2. 在本项目中配置 Key，可任选以下方式之一：
   - **环境变量（临时运行推荐）**：在终端设置 `AMAP_WEB_KEY` 或 `AMAP_KEY`
   - **本地文件（长期使用便捷）**：复制 `amap.local.key.example` 为 `amap.local.key`，将内容替换为 Key。该文件已被 `.gitignore` 忽略
3. 对于 2021-12-02 后申请的 Key，还应设置环境变量 `AMAP_SECURITY_JS_CODE`。请勿把安全密钥写入仓库。

> 如果 Key 曾经提交进 Git，即使后来删除文件，凭据仍存在于历史记录中。请先在高德控制台轮换/作废旧 Key，再使用新的本地配置。

启动时后端会把 Key、安全密钥和随机会话令牌注入本次页面。本地写文件和关闭服务接口会验证 Host、Origin、内容类型和会话令牌。Web 端 Key 与 `securityJsCode` 仍会进入浏览器页面，因此本工具应只在可信本机环境中运行。


## 快速开始

以下以 Windows `cmd.exe` 为例：

```bat
REM 方式 A：使用环境变量（仅当前窗口有效）
SET AMAP_WEB_KEY=你的高德JSAPIKey
SET AMAP_SECURITY_JS_CODE=你的安全密钥
python main.py
```

```bat
REM 方式 B：使用本地配置文件（推荐长期使用）
REM 复制 amap.local.key.example 为 amap.local.key 并写入 Key
python main.py
```

运行后终端会打印访问地址，例如：

```
http://127.0.0.1:54321/
```

程序会在后台自动打开系统默认浏览器。若浏览器未自动启动，可手动访问上述地址。

> macOS / Linux 用户：
>
> - 临时运行：`export AMAP_WEB_KEY=你的Key AMAP_SECURITY_JS_CODE=你的安全密钥 && python3 main.py`
> - 或提供被 Git 忽略的 `amap.local.key` 后执行：`python3 main.py`

常用启动参数：

```text
--port PORT          指定本机端口；默认 0，自动选择空闲端口
--output-dir PATH    指定 CSV 输出目录；默认当前工作目录
--no-browser         启动后不自动打开浏览器
```


## 使用流程

1. **添加多边形顶点**：在地图上点击添加点（至少 3 个）。左侧面板会实时显示经纬度和当前点数。
2. **完成选区**：当点数 ≥ 3 时点击“完成选区”，地图会同时展示多边形、旋转外接矩形及边长信息。
3. **配置航迹参数**：分别设置航向/旁向像幅、焦距、比例尺、重叠率和航速。任意参数变更都会立即废弃旧航迹和旧导出数据。
4. **生成航迹**：点击“生成航迹”。系统在局部米制坐标中优化航向和摄影点，并在地图上展示蛇形航迹与成像范围。
5. **查看统计信息**：右侧信息面板显示有效航线、摄影点、实际点距、实际旁向间距、格网曝光间隔和相对航高。
6. **导出摄影点**：点击“保存摄影点坐标（GCJ-02）”，后端会生成 CSV 文件并反馈保存状态。文件将保存到 `--output-dir` 指定的目录，未指定时为当前工作目录。
7. **重新规划/退出**：可撤销单点或清空任务；结束时点击右上角“关闭服务”，也可在终端按 `Ctrl+C`。


## CSV 输出

- 编码：带 BOM 的 UTF-8（便于 Excel 直接识别中文与表头）
- 表头：`sequence,flight_line,longitude_gcj02,latitude_gcj02,coordinate_system`
- 数据：每行记录摄影点顺序、航线号、GCJ-02 经度和纬度
- 文件命名：`YYYYMMDDhhmmss.csv`；若重名会自动追加 `_1`、`_2` 等后缀

## 项目结构

```
amap.local.key          # 可选：本机 AMap JS API Key（被 Git 忽略）
amap.local.key.example  # 配置示例，不含凭据
main.py                 # 本地 HTTP 服务，负责注入 Key、响应保存/关闭请求

  index.html            # 页面模板，包含 Key、安全码和会话令牌占位符
  *.js / styles.css     # 选点、几何计算、航迹生成、交互逻辑
```


## 常见问题（FAQ）

- **页面空白或提示 “InvalidKey/权限不足”**
  - 确认 `AMAP_WEB_KEY` / `AMAP_KEY` 或 `amap.local.key` 已正确配置
  - 新申请的 Key 还需设置 `AMAP_SECURITY_JS_CODE`
  - 检查 Key 是否已开通“Web 端（JS API）”并允许本地调试域名
- **点击保存后没有生成 CSV**
  - 确认已完成选点并生成航迹（右侧面板显示有效照片数）
  - 确保程序在有写权限的目录下运行
- **CSV 打不开或乱码**
  - 文件采用带 BOM 的 UTF-8。若旧版软件仍无法识别，可使用“数据导入”功能并手动选择 UTF-8
